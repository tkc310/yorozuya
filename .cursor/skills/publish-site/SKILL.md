# GitHub Pages のサイトを公開する

手順・構成・確かめる点・うまくいかないときの対処は [`docs/site.md`](../../../docs/site.md) にまとめている。**まずそれを読み、その手順どおりに進める。**

## エージェントとして守ること

- 公開（`make site-publish`）は外に出る操作なので、頼まれたときだけ行う。頼まれていなければ `make site-build` と `make site-preview` までにして、公開のコマンドを伝える。
- この環境で撮影や公開ができないとき（ブラウザが無い、プッシュできないなど）は、手元で実行するコマンドを利用者に伝える。
- 画面のラベルやボタン名を変えた PR では、`scripts/site/capture.mjs` が追従しているか確かめ、公開サイトの撮り直しが要ることを利用者に伝える。
- LP の文言を変えたら、`docs/improvement/log.md` に記録する。
- CI（`.github/workflows`）にサイトの公開を足さない。`.site/` や撮った画像・動画をコミットしない。
