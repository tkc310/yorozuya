# Conventional Commits

Use `type(scope): description`.

- The type is English: `feat`, `fix`, `test`, `refactor`, `build`, `docs`, `chore`, or `ci`.
- The scope names the area, such as `skill-sheet`.
- The description is imperative and has no trailing period.
- Keep one concern in each commit.
