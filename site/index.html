よろずやとは スキルシート Storybook GitHub

フリーランスのための道具箱

手元で動く、
小さな仕事道具。

よろずやは、フリーランスの仕事のまわりにある細かな作業を片づけるアプリです。 案件やエージェントごとに少しずつ変わる繰り返しの作業を、パソコンの中だけで手早く済ませられます。

macOS 版をダウンロード ソースコードを見る

よろずやとは

  • 繰り返しの作業を楽にする

    案件やエージェントごとに少しずつ形の変わる書類づくりなど、フリーランスの繰り返しの作業をまとめて片づけます。機能はこれから順に増やしていきます。

  • 手元だけで動く

    すべてパソコンの中で完結します。データは手元の SQLite ファイルに保存し、外部のサーバーには送りません。アプリもパソコンの中だけで待ち受けるので、経歴などの大切な情報を安心して扱えます。クラウドもアカウントも要りません。

  • macOS アプリとして使える

    実行環境（Bun）をアプリの中に組み込んでいるので、ランタイムなどを別に入れる必要はありません。ダウンロードしたアプリだけで完結します。アプリを開くと macOS の標準ブラウザでよろずやが開きます。

機能

スキルシート

プロフィール・保有技術・職務経歴を入力すると、業務委託の書類選考で読みやすい A4 のスキルシートができあがります。入力した内容はその場でプレビューに映ります。

入力するとプレビューがすぐ変わる様子

1 ページ目で判断できる

氏名・肩書・経験年数、稼働開始や稼働量などの条件、ハイライトと主要スキルを 1 ページ目の上半分にまとめます。採用担当者が短い時間で判断できる並びです。

  • 経験年数は職務経歴の期間から自動で数えます
  • 保有技術は 0.5 年刻みで、経験の長い順に並べます
  • 項目ごとに、用紙に出すかを切り替えられます

面談でそのまま説明できる職務経歴

自己 PR から職務経歴サマリー、案件ごとの詳細へと、面談で話す順に並べます。 成果は目立つように強調し、担当工程はひと目で分かるチップで示します。

  • 改ページは中身に合わせて自動で決まります
  • 2 ページ目以降にも氏名と更新日が入ります
  • 「抜粋」タグで、特に見てほしい案件を示せます

手元のスキルシートを取り込む

いま使っている Excel や PDF のスキルシートを生成 AI に渡すためのプロンプトを作れます。できた JSON を読み込めば、入力し直さずに始められます。

  • 本文の貼り付け・URL・添付ファイルに対応します
  • JSON の書き出し・読み込みでバックアップもできます
