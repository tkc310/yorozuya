# スキルシートの Markdown 書き出し 指示書

## 目的

エージェントや企業の書類選考で、スキルシートを生成 AI に読ませて一次判定（AI スクリーニング）することが増えている。PDF は段組み・表・タグを画像のように並べるため、文字を取り出すと並びが崩れたり、タグの意味が落ちたりする。そこで、PDF に加えて、同じ内容を Markdown でも選んで書き出せるようにする。

## 決めたこと

- フォーム上部の操作に「Markdownで書き出す」を足す。押すとダイアログで Markdown を見せ、「Markdownをコピー」と「.md をダウンロード」を選べる。PDF（印刷）はこれまでどおり
- 中身はプレビューと同じ `present()` の結果から作る。項目・並び（ヘッダー → 基本情報 → ハイライト → 主要スキル → 保有技術 → 資格・語学 → リンク → 自己PR → 職務経歴サマリー → 職務経歴詳細）・表示の切り替え・イニシャル表示・基準日はプレビューと同じ
- 構造は見出し（`#`〜`####`）・`項目名: 値` の箇条書き・職務経歴サマリーの表で示す。色や段組みには頼らない
- タグは文字で書く（`（抜粋）`・`（主要）`）。抜粋の意味は職務経歴サマリーの前に一文で書く
- 担当工程はチップの代わりに、担当した工程名だけを並べる
- 表の中の改行は空白に、`|` は `\|` にして表を崩さない
- ファイル名は印刷の既定名と同じ（`スキルシート_<氏名>_<日付>.md`）
- 氏名が無いなど `present()` が失敗したときは、ボタンを押せなくし理由を出す
