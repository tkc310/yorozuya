# ドキュメント

よろずやの開発に関する文書の入口です。使い方は [README](../README.md)、開発の手順は [CONTRIBUTING.md](../CONTRIBUTING.md) を見てください。

| 文書                                               | 中身                                                              |
| -------------------------------------------------- | ----------------------------------------------------------------- |
| [improvement-loop.md](./improvement-loop.md)       | 改善ループ（気づく → 記録する → 直す → 再発を防ぐ → 振り返る）    |
| [improvement/backlog.md](./improvement/backlog.md) | 改善候補の一覧                                                    |
| [improvement/log.md](./improvement/log.md)         | 直したことの記録（1 改善 1 行）                                   |
| [decisions/](./decisions/README.md)                | 設計判断の記録（ADR）                                             |
| [site.md](./site.md)                               | LP と Storybook の更新・公開の手順（GitHub Pages）                |
| [ai-agents.md](./ai-agents.md)                     | AI エージェントが読むファイルと、エージェントに任せるときの進め方 |
| [specs/](./specs/)                                 | 機能ごとの指示書（実装前に書く仕様）                              |

設計のルールは [`rules/security.md`](../rules/security.md)、コンポーネントの置き方は [`src/components/COMPONENT_STRUCTURE.md`](../src/components/COMPONENT_STRUCTURE.md) にあります。
