# 0002 想定内の失敗は例外にせず neverthrow の `Result` で返す

- 日付: 2026-10-19（それまでの方針を記録）
- 状態: 採用

## 背景

入力の誤りや、読み込んだ JSON の版違いなどは日常的に起きる。例外で扱うと、呼び出し側が処理を忘れても型で気づけない。

## 決定

- Valibot で弾いた入力は例外にしない
- 想定内の失敗は neverthrow の `Result` で返し、呼び出し側で必ず扱う

## 理由

失敗の扱い漏れを型と lint で見つけられる。

## 影響・トレードオフ

- `oxlint-plugins/must-use-result.js` が、作った `Result` を使わずに捨てるコードを検出する
- 例外は「起きてはいけないこと」（プログラムの誤り）だけに使う
