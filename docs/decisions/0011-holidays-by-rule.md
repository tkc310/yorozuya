# 0011 祝日は表やネットワークに頼らず、祝日法のルールで計算する

- 日付: 2026-11-18
- 状態: 採用

## 背景

作業報告書では、稼働日と残り稼働日数を数えるために祝日が要る。祝日の取り方には、内閣府の CSV や祝日 API を取りに行く、表を同梱する、ルールで計算する、の 3 つがある。

## 決定

- 祝日は `src/shared/features/work-report/holiday.service.ts` で、国民の祝日に関する法律のルール（固定日・ハッピーマンデー・春分日と秋分日の近似式・振替休日・国民の休日・2019〜2021 年の特例）から計算する
- 対象は 2000〜2099 年（春分日・秋分日の近似式が有効な範囲に収まる）
- 内閣府が公表した年（2019・2020・2025〜2027 年）と突き合わせるテストを `holiday.service.test.ts` に置く
- 夏季休暇や年末年始など利用者ごとの休みは、日ごとの「休み」の切り替えで扱う

## 理由

- 画面から `fetch` せず、手元だけで完結する方針（ADR 0001）に合う。オフラインでも動く
- 表を同梱すると、年が進むたびに更新しないと祝日が抜ける。ルールなら先の年も数えられる

## 影響・トレードオフ

- 法改正で祝日が増減したら、ルールとテストを直す必要がある
- 春分日・秋分日は前年に官報で正式に決まる。近似式は 2099 年まで公表値と一致する見込みだが、ずれたら特例として足す
