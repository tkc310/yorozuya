# 0010 開発に使う Node.js を 26.13.0（LTS Lithium）に揃える

- 日付: 2026-11-02
- 状態: 採用

## 背景

開発環境の Node.js は `.tool-versions` の 24.22.1 だった。Node.js 26 は 2026-10-28 に 26.13.0 が LTS（Lithium）になった。

## 決定

- このリポジトリで使う Node.js は 26.13.0 とする
- 版の正本は `.tool-versions` の 1 行（`node 26.13.0`）とする。CI は mise が同じファイルを読む
- README と CONTRIBUTING に書く Node.js の版は、そのメジャー（26）に合わせる

## 理由

LTS の現行版に揃えると、手元と CI で同じ Node.js を使える。版を書く場所を増やさず、すでにあった指定だけを更新する。

## 影響・トレードオフ

- Node.js 24 では動かさない。mise か asdf で入れ直す
- `@types/node` はすでに 26 系（`^26.6.5`）のため、型定義の版は上げない
