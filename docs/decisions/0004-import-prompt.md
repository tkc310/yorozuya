# 0004 元のスキルシートから取り込むために、LLM 向けのプロンプトを出す

- 日付: 2026-10-19
- 状態: 採用

## 背景

利用者はすでに Excel・Word・PDF などでスキルシートを持っている。よろずやは外部のサービスを呼ばない（ADR-0001）ので、アプリの中で変換はできない。

## 決定

- 元の資料の種類を選ぶと、利用者が自分の LLM に渡すプロンプトを出す。LLM が出した JSON を、既存の読み込みで取り込む
- プロンプトに書く項目の説明は `Record<項目, 説明>` で持ち、項目を足したときに説明の書き漏れを型で検出する
- プロンプトに載せる例の JSON は、読み込みのスキーマで検証するテストを置く

## 理由

アプリから外部へデータを送らずに、取り込みの手間を減らせる。型とテストで、項目の追加に追従し忘れるのを防げる。

## 影響・トレードオフ

- LLM の出力の質は利用者の使う LLM に依存する。読み込み時の検証で誤りを弾く
- JSON の版を上げたら、プロンプトの説明と例も更新する
