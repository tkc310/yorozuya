# 0007 コマンドの入口を Makefile にまとめる

- 日付: 2026-10-19
- 状態: 採用

## 背景

`pnpm` のスクリプト、`pnpm exec`、`bun` のスクリプトが混在し、文書や CI に書く形がばらばらだった。

## 決定

- すべてのコマンドを `Makefile` に置き、`make`（または `make help`）で一覧を出す。追加の引数は `ARGS="..."` で渡す
- コマンドを足すときは `package.json` のスクリプトと `Makefile` の両方に足し、文書には `make` の形で書く
- CI と Git フック（lefthook）も `make` を呼ぶ

## 理由

人もエージェントも、覚える入口が 1 つで済む。CI が同じ入口を通るので、`Makefile` の誤りに CI で気づける。

## 影響・トレードオフ

- `make` が必要になる（macOS には標準で入っている）
